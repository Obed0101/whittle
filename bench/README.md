# Benchmark

One question: does a skill change what the agent delivers, and what it costs?

Every arm gets the same model, the same frozen repository and the same request. Only the text appended to the system prompt differs. The agent runs headless in a temporary directory with no user settings, skills, extensions or MCP servers. What it delivered is then scored by checks it never saw.

```bash
python3 bench.py validate
python3 bench.py run --harness claude --model claude-sonnet-5-5 --tasks kanban notes --out runs/mine
python3 bench.py summarize runs/mine
```

Needs Python 3.10+, `git`, `gh` (to fetch the pinned comparison skills) and either `claude` or `pi` on your PATH. A run executes model-written code with permission prompts off; see [`SECURITY.md`](../SECURITY.md).

## Tasks

| Task | Request | Checks |
|---|---|---|
| `kanban` | Two sentences: a complete kanban board, "not a demo" | 40, rubric |
| `notes` | Two sentences: a complete notes app, "not a demo" | 36, rubric, written before any output existed |
| `pricing-page` | A short, ambitious design brief | 26 |
| `expense-report` | A long spec for a CLI | 32, one per requirement |
| `status-page` | A long spec for a generated HTML page | 36, one per requirement |
| `report-over-time` | Four sessions on one codebase, including "cut it down" | 40, cumulative |

The open briefs (`kanban`, `notes`) list no features, so their checks are a rubric of what a daily-use product has. Each check is a pattern search over the delivered HTML, CSS and JavaScript: it shows that something was built, not that it works well. The spec tasks execute the delivered code.

## Arms

`arms.json`. `none` adds nothing. `ponytail` and `caveman` are fetched from their repositories by git blob SHA and verified, so the text tested is exactly the text pinned. `whittle` is `../skills/whittle/SKILL.md`.

## Runs

`runs/<set>/<task>/<arm>/<run>/` holds `score.json`, the `patch.diff` the agent left and, for Claude, the harness's JSON result. `results.md` in each set is generated by `summarize` and checked in CI against the committed scores.
