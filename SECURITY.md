# Security

Whittle is a text file. It installs no hooks, runs no code on your machine and makes no network requests.

Only install it from `github.com/Obed0101/whittle`. A copy that ships executables, hooks or an installer is not this project.

The benchmark does run code: it starts a headless agent with permission prompts disabled inside a temporary directory, then executes what that agent wrote. Run it on a machine where that is acceptable.

Report a vulnerability privately through GitHub's "Report a vulnerability" on this repository.
